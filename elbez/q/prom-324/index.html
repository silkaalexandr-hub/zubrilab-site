При каких режимах заземления нейтрали может предусматриваться работа электрических сетей напряжением 110 кВ, согласно Правилам устройства электроустановок?

ПУЭгруппы III, IV, Vвыше 1000 Впромышленные потребителивопрос № 324 перечня

Варианты ответа

  1. При режимах с глухозаземленной либо с заземленной через резистор нейтралью
  2. При режимах с глухозаземленной либо с эффективно заземленной нейтралью
  3. При режимах с изолированной (незаземленной) либо с заземленной через дугогасящий реактор нейтралью
  4. При режимах с изолированной (незаземленной) либо с эффективно заземленной нейтралью

Почему так

ПУЭ, гл. 1.2: сети 110 кВ могут работать как с глухозаземлённой, так и с эффективно заземлённой нейтралью.
